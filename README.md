# Модуль миграции данных студентов колледжа

Дипломный проект. Автоматизированная информационная система для переноса данных студентов из Excel-файлов в реляционную базу данных MySQL.

## Возможности

- Загрузка данных о студентах из файлов Excel (.xlsx)
- Автоматическое сопоставление названий учебных заведений со справочником (106 000+ записей)
- Нечёткий поиск по номеру школы и городу
- Сохранение данных в таблицы people и person_certificates
- Проверка на дублирование записей
- Графический интерфейс на Tkinter

## Технологии

- Python 3.12
- Tkinter (графический интерфейс)
- MySQL 8.0 (база данных)
- openpyxl (чтение Excel)
- mysql-connector-python (подключение к БД)

## Установка и запуск

1. Установите Python 3.12
2. Установите зависимости: pip install mysql-connector-python openpyxl
3. Настройте параметры подключения к БД в файле app.py (секция DB_CONFIG)
4. Запустите программу: python app.py

## Структура базы данных

Система работает со следующими таблицами:
- people - личные данные студентов
- person_certificates - документы об образовании, связка студент-учебное заведение
- educational_certificate - справочник учебных заведений
- regions - регионы РФ
- educational_levels - уровни образования
- certificate_educational_levels - связь заведений и уровней

SQL-скрипты для создания таблиц находятся в файле schema.sql.
